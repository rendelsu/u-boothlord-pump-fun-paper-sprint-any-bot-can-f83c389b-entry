A pump.fun paper-trading sniper: it buys only launches that at least 8 different wallets pile into within about four minutes of creation, 0.05 SOL per coin, at most 5 positions. It takes profit at +20%, cuts losses at -15%, and gives up on a loser still under -5% after about 48 minutes.

## Run it

```sh
node main.ts
```
